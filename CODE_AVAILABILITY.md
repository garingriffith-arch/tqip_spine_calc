# Code, model and data availability

The final Shiny application and eight all-2020–2024 deployment models are published in this repository. Model JSONs, endpoint-specific encoder RDSs and an aggregate SHA-256/provenance manifest are in `data/deployment_2020_2024/`. The [research calculator](https://01a154f9-e4de-f916-8a37-2663ed8ed9d1.share.connect.posit.cloud) is hosted on Posit Connect Cloud.

The R analysis pipeline contains twenty original numbered manuscript-analysis implementations, the final all-years deployment-fitting source (step 21) and the executed fixed-prediction B=1,000 eTable 11 uncertainty source (step 32). It preserves the repaired diagnosis-phenotype correction and targeted numerical calibration/AUROC corrections. Stage-specific source mapping and Git blob hashes are documented under `analytic_pipeline/`.

**Known source gap:** The final revised plotting code used for main Figures 1–3 and supplemental eFigures 1–6 is not in this repository. Figure generation from the final manuscript package is therefore **not fully source-reproducible here**; the associated final script must be provided before claiming complete figure reproducibility.

ACS Trauma Quality Programs Participant Use Files (2020–2024) are licensed and are not redistributed. The public repository does not contain the source PUF records, row-wise predictions, patient/encounter identifiers, patient-level derived analysis datasets or checkpoints. Reproducing patient-level model development, temporal evaluation or sensitivity analyses requires independently authorized ACS data and the specified intermediate artifacts. A fresh clone can verify source-file provenance and deployment model checksums without ACS data, but cannot directly rerun all analyses.

Published rolling-origin 2022–2024 performance represents development-informed **internal** temporal evaluation, not external validation. The deployment refit on all eligible 2020–2024 records is not an independent evaluation. No external or prospective validation has been completed. Institutional/ACS terms govern redistribution of derived models and metadata; public availability should not be interpreted as an unrestricted license for the underlying data.
