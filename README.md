# SPINE-TRACT

**SPINE-TRACT** is a Shiny calculator for estimating admission-era resource-utilization trajectories after acute thoracolumbar spine trauma.

The app is designed for shinyapps.io deployment and expects the locked model files generated by the TQIP spine modeling pipeline.

## Required files

Place these files in `data/` before local testing or deployment:

```text
data/model_bundle.rds
data/predictor_metadata.rds
```

Optional:

```text
manifest.json
www/ohsu_logo.png
```

## Local test

From the repository root:

```r
install.packages(c(
  "shiny", "bslib", "data.table", "Matrix", "xgboost", "scales", "stringr"
))

shiny::runApp(".")
```

## Deployment

After placing the required RDS files in `data/`, deploy with:

```r
rsconnect::deployApp(
  appDir = ".",
  appName = "spine-tract",
  appTitle = "SPINE-TRACT"
)
```

## Interpretation

SPINE-TRACT estimates observed resource-utilization trajectories, including discharge disposition, ICU admission, mechanical ventilation, prolonged hospital and critical-care utilization, and operative spine intervention. Outputs are intended for early resource characterization and structured clinical communication. They should not be interpreted as treatment recommendations or as evidence that ICU admission, mechanical ventilation, prolonged hospitalization, or operative intervention is clinically indicated.
